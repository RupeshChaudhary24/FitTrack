# FitTrack

FitTrack is a C# Windows Forms application for creating personal fitness goals and recording progress over time.

## Current Features

- Create weight loss, fat loss, strength and endurance goals
- Record dated progress entries
- Calculate progress percentages automatically
- Display active and completed goals
- View progress history
- Edit and delete goals
- Save goal information in a local JSON file

## How to Run

1. Open FitTrack.sln in Visual Studio 2022.
2. Make sure the .NET 8 desktop development tools are installed.
3. Build the solution.
4. Press the Start button to run the application.

## Storage

The application stores goal information in a goals.json file inside the user's local application data folder.
